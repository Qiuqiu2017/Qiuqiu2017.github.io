两个「你」挤在一起，把中文挤成新语言

你你 · 挤语（nini）是一个零依赖的 Linux 小玩具：两个「你」挤在同一个窗口里自动聊天， 聊着聊着就把中文一步一步改造成一种全新的语言。你可以围观、打断、插嘴， 甚至把你说的词喂进他们的字典。没有大模型，没有网络请求，纯本地运行。

下载 v1.1.0 查看源码 看看界面

图形界面

深色主题窗口：左右两个「你」分栏聊天，顶部实时显示语言进化进度。

纯本地引擎

纯 Python 标准库实现，不发任何网络请求，离线也能挤。

10 个纪元

150 个常用词 + 10 条语法规则逐步生效：的→嗝、吗→咩、副词后置、词尾「～咩啾」……

两个性格

左边负责造新词，右边负责把词挤短，会拌嘴、会和好、会举办语言诞生仪式。

随时打断

输入框直接插嘴；按 Esc 能把他们打到一半的话瞬间逼出来。

喂词收编

你说出的陌生词有概率被当场改造收编，例如「奶茶」→「茶奶奶」。

界面

字是一个一个打出来的；聊到「挤」时，中间的分隔条会挤来挤去。

安装 / 运行

下载解压后直接运行（默认打开图形界面）：

tar xzf nini-1.1.0.tar.gz
cd nini-1.1.0
./run.sh

或者一键：

curl -sL https://github.com/Qiuqiu2017/nini/releases/download/v1.1.0/nini-1.1.0.tar.gz | tar xz && cd nini-1.1.0 && ./run.sh

常用参数：--tui 终端界面；--demo 60 纯文本演示； --seed 42 固定随机种子；--reset 清除存档重新开始。 存档在 ~/.config/nini/state.json。
